The 8 Persian test pages

Each page was rendered from text we know, so every mistake can be counted exactly. The classical texts are public domain (Hafez, Saadi); the modern texts were written for this test.

How the Persian OCR test works

  • Every engine reads the same 8 images with its default settings, as its makers ship it.
  • Before scoring, all output is normalised the same way: Arabic and Persian forms of ی and ک, digits, short vowels and Markdown marks don't count as errors. Character errors leave out spaces and the zero-width non-joiner, which Persian writers use inconsistently; word errors count them.
  • Runemic's preview models are called through the public API, like any customer would.
  • Not tested yet: Google Cloud Vision, ABBYY FineReader, Adobe Acrobat and Mistral OCR (paid services). GLM-OCR and LightOnOCR don't list Persian as a language.
