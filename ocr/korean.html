이미지 텍스트 변환 (한국어 OCR)

사진이나 스캔, 스크린샷을 올리면 한국어 텍스트를 읽는 순서대로 돌려드립니다. 제목, 목록, 표를 유지한 Markdown 또는 일반 텍스트로 받을 수 있습니다. 매일 처음 10페이지는 무료이며 계정이 필요 없습니다.

이미지가 없으신가요?

무료 계정으로 계속하기

오늘의 무료 페이지를 모두 사용했습니다. GitHub 또는 Hugging Face로 로그인하고 5달러 무료 크레딧을 받으세요. 미리보기 가격으로 약 2,500페이지이며, 첫날은 50페이지까지, 이후 하루 500페이지까지 사용할 수 있습니다. 모델을 비교하는 플레이그라운드와 API 키도 제공됩니다.

카드는 필요 없습니다. 이 페이지의 무료 한도는 매일 00:00 UTC에 초기화됩니다.

GitHub로 계속하기 Hugging Face로 계속하기

플레이그라운드에서 계속하기

이 페이지의 오늘 무료 한도를 모두 사용했습니다. 로그인한 상태이므로 플레이그라운드에서 하루 500페이지까지 (계정을 만든 첫날은 50페이지) 모델 비교, API 키와 함께 사용할 수 있습니다.

플레이그라운드 열기

이미지는 Cloudflare Workers AI의 공개 미리보기 모델이 읽습니다. 이미지를 저장하거나 학습에 사용하지 않습니다. 개인정보 안내(영어)를 참고하세요.

여기에 텍스트가 표시됩니다.

이미지를 놓으면 읽기 시작합니다

더 정확하게 읽으려면

  • 페이지를 정면에서 밝은 곳에서 찍어 주세요. 줄이 반듯할수록 정확해집니다.
  • 한글과 한자, 영어가 섞인 페이지도 그대로 읽습니다.
  • 표는 Markdown 표로 돌려드리므로 스프레드시트에 바로 붙여 넣을 수 있습니다.
  • 책상이나 손가락처럼 페이지가 아닌 부분은 잘라 내 주세요.

자주 묻는 질문

정말 무료인가요?

네. 계정 없이 하루 10페이지까지 읽을 수 있습니다. 로그인하면 5달러의 무료 크레딧을 드리며, 미리보기 가격으로 약 2,500페이지입니다 (첫날은 50페이지까지, 이후 하루 500페이지까지).

한자나 영어가 섞인 문서도 되나요?

네. 국한문 혼용이나 영어가 섞인 페이지도 각 글자를 쓰인 그대로 돌려드립니다.

손글씨도 읽나요?

또박또박 쓴 글씨는 잘 읽는 편이지만, 흘려 쓴 글씨나 오래된 문서는 어렵습니다. 이런 자료를 위해 자체 모델 Rune-1을 학습하고 있습니다.

로그인했는데, 이 페이지가 제 크레딧을 쓰나요?

아니요. 이 페이지는 로그인한 상태에서도 항상 하루 10페이지의 무료 한도를 사용합니다. 크레딧은 플레이그라운드와 API에서 쓰입니다 (하루 500페이지까지, 계정을 만든 첫날은 50페이지까지).

이미지를 저장하나요?

아니요. 이미지는 모델로 보내지고 텍스트만 돌아오며, 아무것도 저장하지 않습니다. 오늘 사용한 페이지 수만 셉니다.

제 프로그램에서 사용할 수 있나요?

네. 콘솔에 로그인해 API 키를 만들고 이미지를 POST /v1/ocr로 보내세요. API 문서(영어)를 참고하세요.
