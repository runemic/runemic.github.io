تصویر سے اردو متن

اردو متن کی تصویر یا اسکین اپ لوڈ کریں اور قابلِ ترمیم متن حاصل کریں، ان صفحات سمیت جو نستعلیق میں ہیں، وہ خوش خط انداز جس میں زیادہ تر اردو کتابیں اور اخبار چھپتے ہیں۔ ہر روز پہلے ۵ صفحات مفت ہیں اور اکاؤنٹ کی ضرورت نہیں۔

دوسری زبانوں میں OCR: English · فارسی · العربية · हिन्दी

کوئی تصویر نہیں؟

مفت اکاؤنٹ کے ساتھ جاری رکھیں

آج کے آپ کے مفت صفحات ختم ہو گئے ہیں۔ GitHub یا Hugging Face سے سائن اِن کریں اور ۵ ڈالر کا مفت کریڈٹ حاصل کریں: پیش نظارہ قیمتوں پر تقریباً ۲٬۵۰۰ صفحات، پہلے دن ۵۰ تک اور پھر روزانہ ۵۰۰ تک۔ آپ کو ماڈلز کا موازنہ کرنے کے لیے playground اور API کلید بھی ملے گی۔

playground میں جاری رکھیں

آج یہاں کے مفت صفحات ختم ہو گئے ہیں۔ آپ سائن اِن ہیں، اس لیے playground میں آپ روزانہ ۵۰۰ صفحات تک پڑھ سکتے ہیں (اکاؤنٹ کے پہلے دن ۵۰)، ماڈلز کے موازنے اور API کلیدوں کے ساتھ۔

playground کھولیں

تصاویر Cloudflare Workers AI پر ایک اوپن پیش نظارہ ماڈل سے پڑھی جاتی ہیں۔ ہم انہیں محفوظ نہیں کرتے اور نہ تربیت کے لیے استعمال کرتے ہیں۔ رازداری کا نوٹس (انگریزی میں)۔

متن یہاں نظر آئے گا۔

پڑھنے کے لیے تصویر چھوڑیں

بہتر نتیجے کے لیے

  • جتنی واضح تصویر ممکن ہو استعمال کریں۔ نستعلیق میں حروف ترچھی لکیر پر ایک دوسرے کے قریب ہوتے ہیں، اس لیے یہاں وضاحت اور بھی اہم ہے۔
  • ایک وقت میں متن کا ایک کالم لیں۔ کئی کالموں والے اخباری صفحات کالم بہ کالم بہتر پڑھے جاتے ہیں۔
  • صفحے کی تصویر سیدھی اور سامنے سے لیں تاکہ سطریں سیدھی رہیں۔
  • ناموں اور کم استعمال ہونے والے الفاظ کو ضرور جانچیں؛ OCR کی زیادہ تر غلطیاں انہی میں ہوتی ہیں۔

عام سوالات

کیا یہ واقعی مفت ہے؟

جی ہاں۔ آپ روزانہ ۵ صفحات بغیر اکاؤنٹ کے پڑھ سکتے ہیں۔ سائن اِن کرنے پر آپ کو ۵ ڈالر کا مفت کریڈٹ ملتا ہے، جو پیش نظارہ قیمتوں پر تقریباً ۲٬۵۰۰ صفحات بنتا ہے (پہلے دن ۵۰ صفحات تک، پھر روزانہ ۵۰۰ تک)۔

اردو OCR عربی OCR سے مشکل کیوں ہے؟

زیادہ تر اردو طباعت نستعلیق میں ہوتی ہے، جہاں ہر لفظ دائیں سے بائیں نیچے کی طرف جھکتا ہے اور حروف ایک دوسرے پر چڑھ جاتے ہیں۔ زیادہ تر OCR نظام نسخ کے لیے بنائے گئے، جو عربی کا سیدھا انداز ہے، اور نستعلیق کو ٹھیک سے نہیں پڑھتے۔ ہم یہی کمی دور کرنا چاہتے ہیں۔

کیا یہ اردو اخبارات کے لیے کام کرتا ہے؟

جی ہاں، لیکن ایک وقت میں ایک کالم یا ایک خبر لیں۔ پورا اخباری صفحہ ایک تصویر کے لیے بہت زیادہ ہے۔

کیا میں نتیجہ Word یا InPage میں لگا سکتا ہوں؟

نتیجہ یونیکوڈ متن ہے، اس لیے آپ اسے Word، Google Docs یا کسی بھی یونیکوڈ ایڈیٹر میں لگا سکتے ہیں۔ InPage کا اپنا فارمیٹ ہے، اس لیے پہلے کسی یونیکوڈ ایڈیٹر میں لگائیں۔

میں سائن اِن ہوں۔ کیا یہ صفحہ میرا کریڈٹ استعمال کرتا ہے؟

نہیں۔ یہ صفحہ ہمیشہ روزانہ کے ۵ مفت صفحات استعمال کرتا ہے، چاہے آپ سائن اِن ہوں۔ آپ کا کریڈٹ playground میں اور API کے ذریعے استعمال ہوتا ہے: روزانہ ۵۰۰ صفحات تک، یا نئے اکاؤنٹ کے پہلے دن ۵۰۔

کیا آپ میری تصاویر محفوظ کرتے ہیں؟

نہیں۔ تصویر ماڈل کو بھیجی جاتی ہے، متن آپ کو واپس ملتا ہے اور کچھ بھی محفوظ نہیں ہوتا۔ ہم صرف یہ گنتے ہیں کہ آج آپ نے کتنے صفحات استعمال کیے۔

کیا ہاتھ کی لکھائی پڑھی جاتی ہے؟

صاف لکھائی کبھی کبھی کام کرتی ہے، لیکن نتائج بہت مختلف ہوتے ہیں۔ ہمارا اپنا ماڈل Rune-1 انہی چیزوں کے لیے تیار کیا جا رہا ہے۔
