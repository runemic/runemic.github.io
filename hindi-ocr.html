Getting good results

  • Photograph the page straight on, in good light, so the headline bar (शिरोरेखा) of each line is level.
  • Vowel signs (मात्राएँ) and conjuncts are small. A sharper photo gives fewer mistakes.
  • Crop away the edges of the book and anything that isn't text.
  • Check the result for रू/रु, ि/ी and similar marks that are easy to confuse.

Questions

Do I get Unicode text?

Yes. The text comes back in Unicode, so you can paste it into Word, Google Docs, email or a website.

My document uses an old font like Kruti Dev. Does that work?

Yes. Take a screenshot or photo of the page. The OCR reads the letters from the image, not the font, and returns proper Unicode text.

Does it read Marathi, Nepali and Sanskrit?

They use the same Devanagari script, so it can read them. Accuracy varies with the language and the print quality, so check the result.

Can I use it from code?

Yes. Sign in to the console, create an API key and send images to POST /v1/ocr. See the API docs.
