Runemic API

Send a page image and get its text back in reading order, as Markdown or plain text, with tables kept. Use it when you need document text in your product, search index or LLM pipeline and don't want to run models yourself. The preview runs open models; Rune-1 replaces them when it's ready.

  • Today: PNG, JPEG, WebP or GIF in; Markdown or plain text out. PDF input and JSON output come with Rune-1
  • Priced per page, with a lower rate for batch jobs later
  • We don't use your documents for training
  • Sign in with GitHub or Hugging Face and get $5 of free credit
Get an API key Try it in your browser 
# Preview models today; Rune-1 when it launches
curl https://api.runemic.com/v1/ocr \
  -H "Authorization: Bearer $RUNEMIC_KEY" \
  -F "file=@letter.png" \
  -F "model=preview-gemma-4"

# → Markdown text, in reading order
{ "object": "ocr.result",
  "text": "# Letter\n\nDear …",
  "usage": { "pages": 1, "cost_usd": 0.002 } }

Runemic Scan

A scanner app for everyday paper. Take a photo of a receipt, bill, letter or contract, and Runemic Scan straightens it, reads it, picks out amounts and due dates, and files it.

  • Keeps track of bills and receipts
  • Search everything you've scanned
  • Reads Arabic, Persian, Hindi and other scripts, not only Latin
  • Export to PDF, spreadsheets or accounting software
